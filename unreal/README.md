# Unreal Engine version

C++ module of the Unreal Engine 5.8 project `AlbertCanalSwap` (Cesium for Unreal 2.30, OpenXR, Meta Quest 3).

- `SwapExperience`: the guided battery swap story with 7 checkpoints, the swap crane, the lock, battery colours (red at 20% or less, orange below 60%, green from 60%) and live data (Open-Meteo, Elia, AIS).
- `SwapPawn`: viewer for Quest 3 (A/X continue, B/Y change place) and laptop (Space, Tab, right mouse to look).
- `SiteTrees`: the 30,428 surveyed trees as instanced meshes.

The 3D site and models live in the Blender and Unreal project files, which stay in the AImovation project folder.
